🔑 首次使用：填写一次 GitHub Token
Token 只会保存在这台设备的浏览器里（localStorage），不上传任何服务器、也不写进网页源码。 填一次以后就不用了。换设备或清缓存后才需要重填。

点击选择图片，或拖拽 / 粘贴到这里

就绪
图片会存进你的 GitHub 仓库，通过 jsDelivr CDN 分发，永久有效、任何人可访问。

✅ 为什么这次能用
之前用的免费图床（catbox / uguu / tmpfiles…）在国内网络下要么被墙、要么不给跨域头，所以一上传就报“网络错误”。
现在改为调用 GitHub 官方 API 把图片写进你自己的仓库，再用 jsDelivr 分发——这两条通道实测国内直连可用、且都带跨域许可。
🔒 Token 没有写进这个网页里。就算别人打开这个页面，也拿不到你的 Token，只能看你分享出去的图片。
💡 图片是公开的：谁拿到链接都能查看/下载。想删图就去仓库的 images/ 文件夹删掉对应文件即可。
