🎵ImageDrop
上传图片与音频 · 生成公开直链 · 谁拿到链接都能看/听和下载
⚙️ 上传设置
两种方式任选其一：有 GitHub Token 就走「直连」；没有 Token 就走「中转」（由服务端代你上传）。
🔑 方式一 · 直连（自带 GitHub Token）
Token 只保存在本机浏览器里，不上传任何服务器。填一次以后就不用再填。
🛰️ 方式二 · 中转（免 Token，用别人搭好的服务）
填一个中转服务地址（Cloudflare Worker），由它代你把文件写进仓库，你就不需要 Token。
📤
点击选择图片 / 音频，或拖拽到这里
图片：JPG / PNG / GIF / WEBP；音频：MP3 / WAV / OGG / M4A / FLAC 等，可多选
就绪
文件会存进你的 GitHub 仓库，通过 jsDelivr CDN 分发，永久有效、任何人可访问。图片会自动压缩；音频原样上传（建议单文件 < 20 MB）。

✅ 为什么这次能用
之前用的免费图床（catbox / uguu / tmpfiles…）在国内网络下要么被墙、要么不给跨域头，所以一上传就报“网络错误”。
现在改为调用 GitHub 官方 API 把图片写进你自己的仓库，再用 jsDelivr 分发——这两条通道实测国内直连可用、且都带跨域许可。
🔒 Token 没有写进这个网页里。就算别人打开这个页面，也拿不到你的 Token，只能看你分享出去的文件。
💡 文件是公开的：谁拿到链接都能查看/收听/下载。想删除就去仓库的 images/ 文件夹删掉对应文件即可。
🎵 音频会原样上传（不压缩、不改格式），可直接在浏览器里播放；建议单个音频 < 20 MB（jsDelivr CDN 的单文件限制）。
🛰️ 没有 Token 的人可以用「中转」：在 ⚙️ 设置 里填一个别人搭好的中转地址（Cloudflare Worker），同样能免 Token 上传。
